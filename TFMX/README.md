## TFMX

Source snapshot:

- https://ftp.modland.com/pub/modules/TFMX/

This directory contains Amiga modules for The Final Musicsystem eXtended
(TFMX) from Modland. Each playable `mdat.*` module is kept next to its matching
`smpl.*` sample bank, because the player needs both files at load time.

The Modland snapshot lists 369 TFMX module/sample pairs. The `unicorn` pair in
the `- unknown` composer folder is listed by `allmods.txt` but currently returns
404 from Modland, so this snapshot contains the 368 pairs that are available.

TFMX ST material is intentionally not included in this Amiga collection.
