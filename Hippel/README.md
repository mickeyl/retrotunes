## Hippel

Sources:

- https://ftp.modland.com/pub/modules/Hippel%20COSO/Jochen%20Hippel/
- https://ftp.modland.com/pub/modules/Hippel/Jochen%20Hippel/
- https://ftp.modland.com/pub/modules/Hippel%207V/Jochen%20Hippel/

Snapshot date: 2026-05-21

This directory contains Jochen Hippel Amiga modules from Modland in the
`Hippel COSO`, `Hippel`, and `Hippel 7V` formats. Atari ST-facing Modland
formats such as `Hippel ST` and `Hippel ST COSO` are intentionally left out
because this is an Amiga collection.

The Modland snapshot also contains `cryptoburners - pack2.hipc` through
`cryptoburners - pack5.hipc`, `astaroth.hip`, and `amberstar-intro.hip7`. They
were not imported because the current engine does not load them successfully
yet.
